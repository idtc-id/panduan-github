# Lembar Contekan GitHub IDTC

Satu halaman, sepuluh tindakan yang paling sering dipakai. Rujuk modul lengkap di folder [`modul/`](modul/) bila butuh penjelasan lebih dalam.

| # | Tindakan | Langkah singkat | Modul |
|---|---|---|---|
| 1 | Mencari dokumen di dalam repo | Tekan `/` atau klik **Go to file**, ketik kata kunci | M3 |
| 2 | Melihat siapa terakhir mengubah sebuah berkas | Buka berkas → ikon jam **History** di kanan atas | M3 |
| 3 | Bertanya atau berdiskusi | Tab **Discussions** → **New discussion** → pilih kategori | M4 |
| 4 | Menandai jawaban yang menyelesaikan pertanyaan | Arahkan kursor ke balasan → **Mark as answer** | M4 |
| 5 | Mencatat tugas atau usulan | Tab **Issues** → **New issue** → pilih template → **Submit** | M5 |
| 6 | Menutup Issue yang sudah selesai | Buka Issue → gulir ke bawah → **Close issue** | M5 |
| 7 | Mengubah dokumen dan mengajukannya | Ikon pensil ✏️ → ubah teks → **Preview** → **Commit changes** → *Create a new branch and start a pull request* → **Propose changes** → **Create pull request** | M6 |
| 8 | Menelaah Pull Request | Tab **Files changed** → klik `+` di baris untuk komentar → **Review changes** → Approve / Request changes | M7 |
| 9 | Menggabungkan Pull Request | Setelah syarat persetujuan terpenuhi dan semua percakapan selesai → **Squash and merge** | M7 |
| 10 | Melihat dan menyaring papan capaian | `github.com/orgs/idtc-id/projects` → **Capaian IDTC 2026-2029** → kotak **Filter** → `Pokja: "..."` | M8 |

## Ingat selalu

- Semua langkah di atas bisa dikerjakan **hanya lewat browser**, tanpa memasang aplikasi apa pun.
- **Jangan pernah** mengunggah data pribadi, kredensial, atau data mitra tanpa izin tertulis — lihat M9.
- Terlanjur mengunggah data sensitif? **Segera hubungi pengurus**, jangan hanya menghapus berkasnya.
- Butuh bantuan? Tulis di kategori **Tanya jawab** pada handbook Pokja Anda.
